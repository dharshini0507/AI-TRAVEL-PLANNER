# 🌍 AI Travel Planner

AI Travel Planner is an intelligent travel recommendation platform that leverages Google Gemini AI to generate personalized travel itineraries, trip summaries, and destination insights. The application helps users plan trips efficiently based on their preferences, budget, and destination choices.

## 🚀 Features

* AI-Powered Itinerary Generation using Google Gemini AI
* Personalized Travel Recommendations
* Smart Trip Summary with Estimated Budget
* Interactive Destination Maps using Pydeck
* Downloadable Travel Plans in PDF Format
* Support for 100+ Global Destinations
* Responsive and User-Friendly Interface
* Fast Real-Time Recommendations

## 🛠️ Tech Stack

## ⚙️ Installation

### Clone Repository

```bash

```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
